# Product behavior

Appa helps one person turn an intention into a manageable next action, and return after missed work without manually repairing the calendar.

## Calendar assistant direction

The chat supports planning new goals/events through clarification, answering factual calendar-history questions with inspectable references, selecting/previewing calendar moves, and managing the To do list through explicit review and approval. To do actions include add, list, rename, complete, reopen, remove and schedule; matching happens locally, ambiguous items require selection, and applied batches support one Undo. SQLite is the authoritative local store. See [Chat assistant behavior](chat-assistant.md) for flows and supported limits, and [Desktop storage](desktop.md) for migration and recovery. Automated checks use simulated AI responses; real-account and browser interaction verification remain pending.

## Main modules

`src/types.ts` defines the shared goal, task, plan, calendar and API contracts. `src/calendar.ts` owns scheduling, recurrence, recovery, validation and reversible changes. `src/App.tsx` coordinates the calendar views; `src/CalendarTimeline.tsx` supplies the shared Day and Week timeline; `src/CalendarViews.tsx` supplies the month grid, mini calendar and date helpers; `src/Dialogs.tsx` owns planning, settings and goal details. `server/chatgpt.ts` supplies the reusable local OAuth/inference service and browser-development adapter. `desktop/` supplies Electron startup, its private loopback server, and external-link policy.

### Empty calendar slot activation

Double-click empty timed space in Day/Week, empty All day space or an empty Month cell to create an event. Single pointer clicks do not open event creation. Keyboard activation with Enter or Space still creates an event; timed keyboard activation defaults to 09:00. Date navigation and opening existing events remain single-click actions. Explicit Create event buttons remain single-click actions. The same activation rules apply to past dates.
